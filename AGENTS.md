# Project Guidelines

## Working agreements

- Use `uv` as the **sole tool** for Python version management, virtual environments, and package management. Do **not** use `pip`, `venv`, `virtualenv`, `poetry`, or `conda` directly.
- Use `pyright` for type checking.
- Use `ruff` for linting and formatting.
- Use `sqlalchemy` for database toolkit and ORM.
- Use `alembic` for database migration.
